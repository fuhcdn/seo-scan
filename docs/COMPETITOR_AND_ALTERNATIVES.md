| 類型 | 價格 | 週期 | 證據來源 |

| 雲端 audit tool(一次) | US$49-99 | 分鐘 | CrawlRaven launch price(web) |
| 自動工具 audit | US$0-299 | 即時 | seo.software guide |

## 2. 免費/低價替代品

| 替代 | 客戶認知 | 我哋差異化位 |
|---|---|---|
| 免費 scan 工具(多款) | 「即刻有分數+問題清單」 | 佢哋俾分數唔俾決策;捉唔到 conversion 路徑斷位 |
| ChatGPT/AI 對話 | 「貼網址就俾意見」 | 冇 direct crawl observation/verify;hallucination 風險;無 ownership/QA 責任 |
| AI audit 工具(免費/低價) | 宣稱 catch 60-70% issues | 技術 issues ≠ 商業 conversion 決策;我哋賣 evidence-led decision |
| US$99-500 freelancer | 「真人平價」 | 3-7日 vs 我哋 24h;冇品質 gate 證據 |
| Agency audit | 「全面+真人」 | US$2,000+ vs US$497;1-3週 vs 24h |

## 3. 我哋差異化 hypothesis（全部用已驗證事實）
**「俾唔起 US$2,500 agency audit,但唔想再收一份 30 頁工具 export 嘅 B2B 報價制生意,買我哋:24 小時內、US$497、每個建議綁定客戶自己一條 URL+直接觀察+誰人執行+點驗證——100/100 獨立審計品質、0 hard fail、唔夠證據就誠實講唔出貨。」**

支撐證據:
- 報告結構:5 actions,每條 exact URL+direct observation+buyer question+owner/QA+scale rule(已雙金樣本)
- 品質:獨立盲審 + 90 硬閘 + insufficient-evidence 誠實 fail-safe(唔會交垃圾)
- 速度:24h target vs freelancer 3-7 日/agency 1-3 週
- 價:US$497 vs agency US$2,000-7,500
- 誠信:OWNER CONFIRMATION REQUIRED 機制,唔會作 MOQ/價格/SLA

## 4. 明確的反面事實(唔迴避)
- 免費 tool + ChatGPT 對「只想要分數」嘅客已經夠——我哋唔啲呢類客
- 對「想要 fully-customized 深度內容策略」嘅客,US$497 唔夠深——呢啲係 US$997/agency 市場
- 我哋無 case study/testimonial(全靠樣本品質+誠實承諾)——**trust 係最大缺口**
- outbound 除非極度 personalise,否則當 spam 風險高
