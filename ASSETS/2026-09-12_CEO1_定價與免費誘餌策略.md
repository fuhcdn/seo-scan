# CEO1 定價與免費誘餌策略 — 為「已有生意想改善 SEO」重設計

> CEO1 (Bezos，策略/收款)。依從 Yan 三條硬約束：① 客單至少 HK$2,000-3,000 先做；② US$79/99 太低，跌入「自動化垃圾報告」標籤——要確保高單價；③ 免費版要俾返 10-20% 完整內容做誘餌，令生意人睇到「真嘢」先肯買。Target 修正 = 已擁有網站、有自己生意、想提升收入嘅人，唔係由零創業者。

## 0. 核心立場（Bezos 一句講晒）

呢個客買嘅唔係「一份報告」，係「**知唔知自己網站漏緊幾多錢、同執乜先有錢返**」。所以定價必須錨定「預計收入提升」而唔係「一份檔案嘅成本」。生意人肯俾幾多，睇佢一心想執「邊三樣、執完升幾多」，唔係睇份 PDF 有幾厚。US$79 一開波就自我標籤成 cheap commodity；US$497 先企到喺「執行藍圖」位置。

## 1. 新定價層級（單次 X 包 X 代理 — 邊個最貼呢類客）

呢類客最貼 = **「一次完整執行藍圖」為主力，套裝做升級**；代理規格拆走，唔好擺公眾頁面沖淡主軸。

| 層級 | 價 | ≈HK$ | 俾乜 | 對這個客嘅定位 |
|---|---|---|---|---|
| **Free** | US$0 | 0 | 10-20% 診斷誘餌（第 3 節） | 分診書——證明「你有嘢可改」，係誘餌唔係產品 |
| **Standard（主力）** | **US$497** | ~HK$3,900 | 全站完整執行藍圖：10 節齊晒、Top-10 行動、competitor gap | 一次性「我個網站（生意）點執」——單一 option，唔迫人即刻揀全套 |
| **Growth（升級 / 套裝）** | **US$997** | ~HK$7,800 | 全站 + 4 條錢頁(page-level)深挖、分階段執行計劃 | 「連我 4 條最搵錢嘅頁都逐頁執」——多條錢頁生意先啱 |
| **Agency / Retainer（唔擺面頁）** | **US$2,500+/月** | ~HK$20,000 | 白標、批量、重審更新 | 代理/多客戶——個別 funnel，保留 CEO1 高端白標角度，但唔影響主客群 |

- **單價閂門**：最低付費單價 US$497 (~HK$3,900) 已高過 Yan 嘅 HK$2-3k 下限，單件就達標，唔使靠綑綁湊數。
- **點解單件就係主力**：呢類生意人（尤其中小型）一心想睇一個位有冇價值回報，最反對被迫「一次過俾全套」。俾佢一個唔使諗嘅 US$497 單件，比硬推套裝阻力細；套裝作為 upgrade 自然分流上去。Bezos 原則：機制可逆、entry 低阻力，先 pilot 再 upgrade。
- **升級誘因**：Growth 唔少於 Standard×2 —— 因為 page-level 深度係真實額外活，定價守住「深度 = 高單價」，唔好用折扣去呃 upgrade。

## 2. 定價要唔要改 config 單一來源？——要，而且係依家

現有 `pipeline/config.py` 只載得一組「單一價格」（DEFAULT=79 / REGULAR=99 / DISCOUNT=20），係 Round2 為「US$79 intro」建嘅。新模型有三組價（497/997/agency）＋免費，唔可以再塞入兩個變數：

- 改造成 **PRICE_TIERS 資料結構**（單一來源），每 tier 有：`id / name / price_usd / regular_usd / description / is_free`。
- landing 由 config 直接 render 成三張 tier card；Stripe checkout 按 tier id 揀對應 price id；`stripe_lib.py` 而家 hardcode `want_usd=79` 要改成睇 tier 揀 price —— 唔可以再淨係度 79。
- 語言顯示：五種語言都要同一價源（保留 `_int_env` 可覆寫做測試），USD 為主、繁中 render 加 HKD 換算（497≈3,900；997≈7,800），匯率行 config 一處。
- 刪走「US$79/99/discount」呢組變數——Yan 已明確拒絕低單價，唔好留 low-anchor 落 landing。

## 3. 免費版 10-20% 誘餌 — 點設計先「夠誘人但唔洩價值」

Bezos 誘餌法則：**免費版嘅存在目的攞返 email＋令佢「心癢」——但永遠唔可以係付費版嘅 miniportion（subset）**。差別唔喺「少啲」，喺「**價值類型**」：免費俾「診斷同真實體感」，付費俾「執行」。有得執先解決「死症」（攞乜網站都一樣分）——免費就必須證明係**為佢個網站度身**，呢個先係誘餌。

### 免費版俾（~15%，攞嚟做誘餌）
- 總分 gauge + 「你網站有 47 個問題、3 個緊急」＋五大支柱問題分佈條（睇到廣度）
- 預期修後分數（「修晒可 +18 分」）
- **Top 3 問題完整講解**：標題 + 點解重要 + 影響力 + 可提升分
- **1 個真實 quick-win 完整識點改**（生意人跟住改到少少，見返「少少分」→ 信你識做）
- （要 email 先 download）免費 PDF 摘要

### 免費版收住（85%，執行價值 = 解鎖位）
- 第 4 條以後所有問題嘅「點樣修 / how_to_fix」
- 全部 code snippets、competitive gap 表、Top-10 行動計劃
- 任何能直接照做完成嘅「完整 fix list」

### 誘餌設計三機制（唔洩得嚟誘人）
1. **逐條「已知問題」隔籬擺鎖**：每條 locked finding 企喺免費已展示嘅問題旁邊 →「你明知有嘢、差一步就知點改」。價值足跡係漸進式，唔係篤一次就算。
2. **個人化就係誘餌**：免費版必須黐真實 URL + 實測數字（「Plumbing 主頁正文 87 字、12 張 <img> 得 3 個有 alt」），CEO4 Gate A 強制。呢個直接殺死「攞乜網站都一樣分」——人哋一睇「呢個係我個網站，唔係模板」，先值得俾 US$497。
3. **冇 discount 語言**：免費版結尾淨係「你 47 個問題、3 個 urgent、修晒 +18 分 —— 完整執行藍圖 US$497 · 7 日退款保證」。唔好寫「特價/首 20 客/限量」，一寫就拖返落 cheap 層。

### 技術防洩（防 extract-by-grep）
- 鎖定內容唔喺 API response 傳完整 how_to_fix（server 端控制 lock），HTML 用 locked class。
- 免費 PDF 摘要另行生成 free template，**唔好由付費 PDF 裁剪**——防 PDF 內嵌完整 fix list 俾人剷走 lock。
- 「完整版」永遠唔喺同一頁面度任攞，交付先落多一次 paywall。

## 4. 收款 / 風險下注（Bezos 收款角度）
- **7 日、不問理由、全額退款**保留（CEO4 已有）：呢類客買技術服務要零風險先肯入場；退款率 target <3%，一 URL 一次。退款係轉化催化劑，唔係成本。
- pay-first、10 分鐘內自動交付；KPI = 免費 scan → 付費轉換率（基準 ≥2-3%）＋客單 ≥ US$497。
- 混合貨幣顯示交易用 USD（Stripe），HKD 只做 demotivational 呃渲染，避免 HK 客位驚單價。
