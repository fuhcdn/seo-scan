# CEO2（Jobs 腦）— 深度個人化審計報告 + 免費版 10-20% 內容 設計方案

角色：CEO2 產品/質素/品味
問題：Yan 指出 4 個死症（質素普通、深度唔夠、冇改進方法、攞乜網站都一樣分數）+ 免費版要俾返 10-20% 內容。

## 一、核心立場（一條主線）

審計唔係一份「量度報告」，係一份「診斷」。

醫生唔會讀血畀數字你聽——佢話你知你有咩病、點解、點醫。而家個報告就係「量度」而唔係「診斷」，所以先會「攞乜網站都一樣分數」。

**呢個先係真正病根，唔係 engine 出錯，係成個產品假設錯咗。** 由「42 項 checklist 燒數」改成「一份針對你呢間公司嘅診斷同醫程」。報告由一句『site thesis』做脊椎，每段都餵返俾嗰句。

## 二、個性化引擎 — 直接殺死「一樣分數」

分數同 fix 唔可以由固定 checklist 出，要喺 **5 個 pass** 度由 AI 為「呢個網站」重砌。每個 pass 輸出一個 site model 俾下一個 pass 用：

**Pass 1 — Site Model（身份）**：AI 讀成個 crawl 內容，做「呢間公司係咩」：行業、business type、地區範圍、目標客、點賺錢（monetization）、邊幾頁係錢頁（money pages）、寫作語氣/語言。例：「你係一間主打緊急水喉維修、覆蓋中環至灣仔、靠電話報價賺錢嘅本地服務商。」—— 呢個模型字字寫入報告 header，任何第三方一睇就知唔係 template。

**Pass 2 — Intent Map（意圖地圖）**：抓返呢個網站「應該排」同「而家排」嘅錢關鍵詞。唔止爬自己內容——接 GSC（Google Search Console 匯出）/ Bing Webmaster API 嘅真實 rank（v1 用 Bing WP free tier + 競爭對手 SERP diff；GSC 做可選 premium 訊號）。產出：「你而家喺『緊急水喉維修』排 #7，喺『爆水管緊急維修』完全唔入局。」

**Pass 3 — Weighting（個性化權重）**：分數唔係固定公式。每個 business type 有自己一套 pillar 權重：
- 本地服務商：NAP 一致、GBP、reviews、schema、電話轉換 → 權重極高
- E-commerce：product schema、速度、分頁架構、圖片 alt → 權重極高
- 內容站/SaaS：主題權威、site architecture、內連、EEAT → 權重極高

兩個唔同行業差唔多質素，分數因為權重唔同而唔同；就算同一分數，「點解」都唔同。**呢個直接打碎「一樣分數」。**

**Pass 4 — Fix Generation（原生 fix）**：每個 finding 必須錨實三樣嘢：(a) 一個真實觀察到嘅 signal 連實際數字，(b) 個 Site Model，(c) 一條真 query / 一個真競爭對手。提示規則：**冇 site-specific anchor 嘅 generic issue 一係降級、一係剷走。**「圖片無 alt」要寫成「你首頁 31 張圖得 2 張有 alt，其中 5 張產品圖直接拖『…』條 query 嘅圖片搜尋」。

**Pass 5 — Uniqueness Gate（個人化閘門）**：出報告前做質檢，Job 式「呢份唔可以係 template」：
- 必須含一句引用真內容嘅 site thesis
- 必須含 ≥K 條可驗證嘅量化事實（真數字：幾多張圖、幾多字、排第幾）
- 每個 top fix 必須引用真 URL / 真 query / 真競爭對手

三關過先出；唔過帶「你太 generic，要 quote 具體數據」再跑一轉。**呢個先係結構性保證每個網站唔同，唔係靠手氣。**

## 三、深度 — 點解可以做到「知道我網站點解唔好、點解係咁排、執邊樣先」

深度唔係更多項目，係四層「點解」逐層解釋：

1. **點解你排行咁**：抓返 per-query rank，逐條講「你排第幾、隔籬係邊個、人哋點解羸你」。例：「你喺『爆水管緊急維修』唔入局，因為你冇呢條 query 嘅專頁、標題又冇呢個詞——排 #1 嘅競爭對手有 2,400 字內容 + 明確 24 小時服務信號，兩樣你都冇。」
2. **點解呢個係問題（cost framing）**：每個問題講佢喺「呢間公司」身上賠咗幾多——留住冇入局嘅錢 query 唔見幾多曝光。唔好淨係話「有問題」。
3. **點解呢個做法得（mechanism）**：每個 fix 嘅機制要解釋——「改標題 + 加呢條 query 入去，令 Google 重新判斷你主題，係最直接、成本最低嘅 signal 改動」。
4. **錢頁優先**：一切由「錢頁 + 錢 query」出發。唔好平均落粒嘅 common 問題，而係問「邊個 gap 令我最主力嗰條錢 query 排唔上」。先醫錢頁，後先周身。

**結論：深度 = 「leak 逐層拆」+「每樣嘢連返一條真 query 同一個真競爭對手」。**

## 四、改進方法 — 每個 fix = 具體做法 + 點解 + 預期效果

每個 finding 固定「三件套」（呢個係 Jobs 最硬嘅質素 bar）：
- **具體做法（How）**：唔止理念，要行到——改邊一段、貼咩 code、邊個 schema snippet、SEO 工具入面改邊格。加「落手 3 步」。
- **點解（Why）**：機制 + 引用真 query。話俾客知點解咁做，而唔係淨係吩咐。
- **預期效果（Effect）**：量化 + 有 confidence。例如「改標題呢個結構（你對手 #1 正正係咁）有望令『緊急水喉維修 中環』由 #7 升上 top-3；低風險、今日可做。」

再包兩層：
- **Effort 估時（0-1 鐘 / 1-4 鐘 / 1-3 日）+ Impact 分（低/中/高）** → 直接出「執邊樣先」。
- **優先排序唔係按技術類別**，係按 **impact ÷ effort** 排；頭 3 條就係「今日/本週做呢三樣」嘅行動計劃。

## 五、報告骨架 — 一條主線，唔係 42 項燒數

1. **封面 + 一句話結論（The Thesis）**：成個報告一句講晒，例如「你問題唔係內容唔夠，係 Google 唔知你出名做咩。」每位客都唔同，呢句係個 hook。
2. **醫程總覽（Executive Summary）**：總分 + 三項「今日做」+ 一句「你死症係咩」。全部寫個人化事實。
3. **點解你排行咁（診斷故事）**：per-query rank reality 逐條講。
4. **三大槓桿行動（Top-3）**：淨三條，每條三件套齊。
5. **問題全景（漏斗式，唔係技術類別）**：由「高 impact / 低 effort」到「低 impact / 高 effort」排，約 15-25 條（唔係 42）——少而每條都重秤。入「做咗有咩回報」，唔入睇唔明嘅技術分類。
6. **競爭對手 gap（可選 premium）**：真 top-3 競爭對手逐 query diff。
7. **附錄**：全量技術 finding 逐項，一樣三件套。

**刪嘢（Jobs：「我哋對咩講唔」）**：唔講 42 項堆砌、唔輸出「你內容太少」呢啲冇錨嘅 generic 廢話、唔做睇唔明嘅技術分類、唔俾冇「點解」嘅單項 listing。數量係品質，少而重秤。

## 六、免費版 10-20% 點畫 — Show 真值、留住付費

**Jobs framing：醫生唔會收錢你先知自己有病——佢免費睇你「佢知唔知你個病」，至收錢「點醫」。免費版 = 俾「診斷嘅 wow」，收費版 = 成個「醫程」。**

**免費版（約 10-20%，但全部係「真嘢」——呢個先係賣點）：**
- Site thesis 一段（真、獨特、引用你內容）→ 即刻證明唔係 template
- 總分 + 計分理據（基於幾多個 signal）
- 第一條最高槓桿 finding 完整三件套（做法 + 點解 + 預期效果）→ 示範格式，又多獨有
- 之後 3-5 條 finding 淨係標題（teaser）
- 明確話你知付費版有咩（scope framing + CTA）

**收費版（另 80-90%）：** 全部 finding 完整、三大槓桿行動計劃、effort/impact matrix、競爭對手 gap、keyword/rank 數據（邊啲 query 排邊度）、逐 fix 落手步驟 + snippet、GBP/schema 全部可做嘢、每 fix「可加幾多分」嘅 uplift 估算、靚 PDF + email。

**畫線原則（最緊要呢條）：免費版俾晒「診斷」，收費版先俾「醫程」。** 診斷製造 wow + 信任（「佢真係知我網站」），醫程先有真正行動價值。所以免費版明知唔好俾：完整 fix list、任何競爭對手/rank 數據、effort/impact 排序、snippet/落手 method——**呢啲先係客會俾 US$99 嘅嘢。**

呢個完全對齊 ladders：免費 scan 入門 → $99 單次 → $350 4 次包。免費示範做到真值，先有人行上去。

## 七、驗證「唔同」嘅測試（俾 Vince / 自己啪）

- 攞兩個**完全唔同行業** URL 各跑一次 → 比較報告開頭 thesis 段，相同用字唔可以超過約兩成。
- 攞**同行業兩個唔同站** → top fix 唔可以一樣（錨唔同 → fix 唔同）。
- **Personality test**：報告必須含 ≥K 條可以俾第三方核實嘅獨有事實（幾多張圖、幾多字、排第幾、邊句 title）——數唔夠即 reject 再跑。
- **A11 獨立 verifier**（skill 規則 4）：唔准 producer 自認自己唔同，要第三者睇證。

## 八、成本 / 取捨（老實講）

多 pass = 每個 audit 多 4-5 次 LLM call（都係 cheap：site model + intent + weighting + fix + gate），加 SERP 數據源。但呢個正正就係評分卡護城河標準（Jensen：「深度係咪真默池」）——而家個「20 個 common 問題頂住」先至係「默池假象」。喺 US$99 價位，個性化 + 行動力先係值嗰個價、先至唔會被免費 scan 撼低。
