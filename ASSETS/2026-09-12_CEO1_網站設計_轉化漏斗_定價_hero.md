# CEO1 網站設計 — 策略／轉化漏斗／定價頁／hero

> CEO1 (Bezos，策略/轉化)。對齊已定決定：定價 US$497 主力 / US$397 早鳥(創始定價) / 免費 10-20% 診斷(俾+執行收) / 權威徽章 / 5 語言 / 7 日退款用「交付前可退 + 交付後免費重審」。
> Target = 已經有網站、有自己生意、想改善 SEO 提升收入嘅人 — 唔係新手、唔係由零創業者。
> 呢篇係直接可執行嘅設計規格：每格有定位 + 實字 copy + 佈局順序，落地 team 照砌就得。

## 0. 一個總原則（Bezos，全站 every decision 都跟呢句）

呢個客買嘅唔係「一份報告」，係「知唔知自己個網站漏緊幾多錢、同執邊幾樣先有錢返」。
所以全站任何字眼，都唔好講「learn SEO」「start your journey」「beginner course」呢類新手語言——一講就跌返落「俾初學者睇嘅免費工具」層級，一拳打走我哋嘅 target。
一切以「生意損失 → 點執 → 預期收入提升」嘅老闆視角寫。老板唔係識唔識 SEO 嘅問題，係「邊個幫我決定邊三樣優先做」。

「Already have a site」喺每屏都要 feel 到：我唔係教你由零起步，我係幫你執好個已經喺度嘅生意引擎。

## 1. 首頁架構 — 點令「已有生意」嘅人一眼知價值

順序＝直接照呢個從上到下鋪。目標：首 3 秒判生死（第一屏），往下每屏都要「earn its place」，多餘嘢斬走。

1. Sticky 導覽（極簡，唔似工具站）
   左：logo｜中間：單一 CTA「免費 Scan」+ 5 語言切換器（繁中/簡中/EN/ES/FR by 已定5語）｜右：淨低唔用。
   原則：成條 nav 得一粒動詞 CTA，唔開多條路（landing-pages skill：單 CTA）。

2. Hero（見第 4 節，全頁最重要）— 直接放掃描入口，一入來就 action。

3. 權威徽章條 Trust Bar（見第 6 節）— 第一屏就要。

4. 「你係咪遇到呢啲？」問題攪動（3 條，老闆一眼認得）
   「你個網明明有客質量，但 Search 排名唔郁。」／「你唔知自己邊幾條頁最多問題，淨係 feel 到生意少咗。」／「你以前用嘅 SEO 工具淨係俾你睇一堆數字，冇話你聽執邊三樣。」
   呢 3 條改造成「自己就係嗰個老闆」，分別發覺到痛，先有誘因行落去。

5. 我會俾你乜（Benefit-led，唔係 Feature-led）
   唔係列「crawl、評分、660 指標」，而係：
   「我會用業界標準（Google Search Essentials / Core Web Vitals）掃晒你成個站，話你聽有幾多個問題、邊啲係緊急、執晒可升幾多分。」
   呢一句已經企到係「針對你個站」，唔係 tool。

6. 真實診斷示範（關鍵，convincer）
   放一個**真實網站嘅免費診斷截圖/animated**（show 總分 gauge + 「你嘅網站有 47 個問題、3 個緊急」+ 1 個 quick-win 完整修法）。
   注意：一定係真人網站嘅免費版輸出（Gate A 綁實 URL+數字），唔好用假 data——呢個先係「我識嘢、而且係針對你」嘅鐵證。

7. 點行（3 步，簡化）
   Step 0 貼 URL（免費，唔使註冊）→ Step 1 3 分鐘出診斷（10-20% 俾你）→ Step 2 解鎖完整執行藍圖（即時交付）。
   每步底下補一句「X 分鐘 / US$0 / 即時」。

8. 權威背書（Authority）— 業界標準徽章 + 一句「跟 Google Search Essentials、Lighthouse、Ahrefs-metric 基準做；每條 finding 附實測證據，唔係模板」。

9. 定價 teaser（輕觸）— 主席「由 US$497 起」，連結去定價頁。唔喺首頁落重錘，主力頁係定價。首頁淨係「sell 個診斷」，定價留俾已經睇到有嘢改嘅人。

10. FAQ（5 條 objection，落地 team 照寫）
    我已經有 SEO 代理，仲需要？→ 呢份係話你聽「個代理係咪交到嘢」嘅獨立第二意見。
    我唔識 SEO，睇得明嗎？→ 每條「問題→對你生意影響→點改」，第一頁係老闆摘要。
    同免費工具（lytics/PageSpeed）有咩分別？→ 免費工具俾你數字，我俾你「執邊三樣、預期升幾多」嘅決定。
    我要即刻俾錢先睇到？→ 免費先睇 10-20% + 1 個 quick-win，確認有嘢改先決定；完好先俾錢。
    驚買咗唔啱→ 交付前可全退，交付後免費重審 30 日。

11. 風險反轉 + 最後 CTA — 7 日退款保證 badge + 重複一次掃描框（成個落地流程最後都係返去 scan，唔係去別處）。

12. Footer — 5 份合規文件（ToS/私隱PDPO/授權書/免責）＋語言切換＋聯絡（one-way auto-responder）。

「已有生意」點樣喺架構層面上 feel 到：
- 冇「課程」「教學」「初學者」門。
- 問題攪動 3 條全部係「已經有網站」先會有嘅痛（新手唔會 feel 到）。
- 示範係真實網站嘅輸出，signals「我幫緊經營緊嘅人」。
- 最後 CTA 唔係「sign up to learn」，係「scan 你個站」。

## 2. 轉化漏斗 — 免費 scan → $497 → 交付，三日內第一單

漏斗五格，每格有 metric，KPI = 免費 scan → 付費轉換率 ≥2-3%。

Step 0 免費 scan（零摩擦）
首頁 hero 直接個 URL 框，唔使註冊、唔使 email。一次 scan。目標：最多人入，唔設任何門檻。

Step 1 即時診斷（免費 10-20%，核心誘餌）
出一版「分診書」：總分 gauge + 問題總數/緊急數 + 五大支柱分佈 + Top 3 完整講解 + 1 個真實 quick-win + 預期修後分數。
每個鎖定項目就企喺「你已經見到嘅問題」隔籬——「你明知有嘢、差一步就知點改」。呢個「遞增價值足跡」先係免費版嘅誘餌 engine（唔係一張分數卡就收人 email）。

Step 2a 立即付款（主路徑）
每條 locked finding 下嘅 CTA：「解鎖完整執行藍圖 US$497」+「7 日退款保證」badge。
pay-first：一撳就入 Stripe checkout，唔拖。

Step 2b Email capture（副路徑，撳唔到付款嘅人）
「免費 PDF 摘要」門住 email。呢個係真回報：lead generation。2-3 日後自動送「你 Top 1 問題嘅完整修法」做甜頭再 push 一次（內容再俾多一項 now-to-fix），提醒完整版價值 +「報告會因應 SEO 變化更新」嘅時效逼切。

Step 3 交付（pay-first、即時）
付款 → 10 分鐘內自動出完整 PDF/網上版 → recap email 帶客名 + FAQ + 一句「唔明邊度直接覆呢封」。Keep 全自動。

### 三日內第一單嘅實際途徑（唔可以齋靠有機流量）

單靠上線嗰日嘅有機訪客，三日內未必有客。要 threat：
- 並行 assisted closing：上線同時，Yan 用 3 間 warm lead 公司，人手 send 一封「已幫你個站做咗一次免費診斷」+ 各自個性化診斷截圖 + 一條直接 Stripe 付款 link（$397 創始價）+ 即日交付。呢個唔使等 SEO，係第一單最快來源。
- Self-serve 同時行：Stripe checkout 依家就要開好（15 日收錢路徑 Day5 已開 pay link 邏輯），確保任何一個有機訪客撳得到、即時收得到錢。漏斗任何一步斷咗（無付款 link）＝成個 funnel 廢。
- Telemetry 由第一天就收：記錄每個 drop-off 位（scan→診斷→付款→交付），有用先好改，唔好亂 test。三日後睇轉換率有冇行近 2-3%。
- 7 日退款保證由第一天就講明：呢個唔係成本，係催化劑——生意人買「唔肯定嘅技術服務」要零風險先肯入場。

三日拍板 checklist：①Stripe checkout 攞得錢 ②hero scan 即時出診斷 ③付款即時交付 ④3 封 warm lead 手動 link 已經發出 ⑤funnel telemetry 緊住。呢 5 樣齊，先叫「可以計三天 KPI」。

## 3. 定價頁 / 早鳥 $397 — 點樣唔 cheap 但緊迫

### 原則（Bezos 反 cheap 核心）

「$397 早鳥」絕對唔可以用 discount 語言（「特價/限時 20% off/殺到 $397」），一寫就跌返入「自動化垃圾報告」層級，同我哋嘅 US$497 定位直接打架。
正解：將 $100 差額重新 frame 做「創始承諾定價」（founding pricing）——早鳥買家俾嘅唔係「買平」，係「喺產品仲幼嫩嗰陣就信任佢、並提供反饋/見證」嘅交換。呢個先係「唔 cheap」嘅 urgent。

### 定價頁佈局（兩層 tier + 創始條款）

上層：一小條「創始定價」banner（見下）。
中部：兩張 tier card 並排（Standard US$497 / Growth US$997）。Growth 係 decoy——令 $497 望落合理（anchoring），同時分流「多條錢頁」客。
底層：風險反轉 + 常見問題 + 最終 CTA。

Standard（主力）US$497 ≈ HK$3,900
- 全站完整執行藍圖：五支柱 + Top-10 行動 + 競爭差距表 + 90 日 roadmap + code
- 每條 finding：問題/證據(真 URL)/點解蝕錢/點改/預期效果/effort
- Site-type 指紋（偵測到你係電商/本地/內容⋯）——證明唔係 template
- 7 日退款保證

Growth（升級）US$997 ≈ HK$7,800
- 成個 Standard + 4 條「最搵錢頁」page-level 深挖 + 分階段執行計劃
- 定價守住「深度=高單價」：Growth ≥ Standard×2，唔用折扣呃 upgrade

Email capture CTA（唔想立即揀 tier 嘅人）：「落返個免費 PDF 摘要先」→ 入漏斗 Step 2b。

### 創始條款點 display（唔 cheap 但有緊迫）

- Frame 名：呢個唔叫「discount」，叫「Founding Pricing / 創始定價」。文案照呢份寫：
  「創始定價 US$397（Launch 後 US$497）—— 俾頭一批信任我哋、並接受『報告交付後可能微調』嘅早期客戶。創始價永久鎖定，回報係你提供一則誠實見證 / 允許我哋用你個案做案例研究。」
  呢句將「平 $100」變成「價值交換」（你俾信任+見證，我俾鎖定價），唔 cheap 之餘仲有內在緊迫。
- 緊迫要真實，唔可以 fake：一個**誠實**嘅創始窗口——
  「創始定價截至 2026-09-26（上線後 14 日）或填滿首 20 個創始位 — 先到先得」＋ live countdown（剩餘日數/位數）。
  關鍵：日期同額數要係真、要 record 低、到時真係會關。fake perpetual 24hr timer 先會傷信任、仲會令成站 cheap。
- 緊迫同風險分開講，唔好撈亂：
  「$397 係關於價格嘅緊迫」── 窗口/名額。
  「交付前可退 + 交付後免費重審」係關於風險嘅解除 ── 呢個同創始價係兩樣嘢，擺喺唔同位（創始條款喺 banner，退款保證喺每張 card 同 checkout）。分開，確保退款保證唔被「限量」short；創始價又唔被「可退」拖低價值感。
- 絕唔喺定價頁用「首 20 客 US$79」呢類舊低錨語言（決策已刪）。呢個客睇到 $79 會即走。

### Anchor 一句幫 $497 企穩

FAQ：「US$497 同免費工具差喺邊？」→
「免費工具俾你一堆數字。我哋喺 PC space 度用 Google Search Essentials / Core Web Vitals 標準，幫你做成 90-日、按 impact-effort 排好嘅執行藍圖——你唔使學 SEO，淨係跟住做，預期升幾多分我哋都計俾你睇。呢個先係生意層級嘅答案，唔係工具層級。」

## 4. Hero — 放乜、掃描入口放邊、可信信號放邊

### Hero 佈局（由左至右，或 mobile 由上至下）

眼眉 line（細）：For businesses that already have a website — 你已經有生意，呢度幫你執好個站。

主標題 H1（收益主導，唔用 SEO 術語做 hook）：
「搵出你個網站點解漏緊客——同執邊幾樣，先會升返上排名第一位。」

副標題 H2（承接，加價值預告 + 降摩擦）：
「我哋用業界標準掃晒你成個站，3 分鐘內俾你一份免費診斷：你有幾多問題、邊啲緊急、執完可升幾多分。唔使註冊、US$0、即時出。」

主 CTA — 掃描入口放最中央、第一屏、正對 H1（成個 hero 嘅唯一 action）：
一條大 URL 輸入框 + 綠色大掣「免費 Scan　→」。
底下細字（Risk + 實用信號）：「免費診斷 · 唔使註冊 · 唔使 credit card · 3 分鐘出結果」。
呢條入 cue 唔需要 email，因為 Stage 1 目的係「最多人 scan」，email 留俾 Stage 2 個 PDF download 先收——分兩段，第一段零門檻先令漏斗頂部夠闊。

### 可信信號放邊（三層，唔好堆埋一堆）

第一層（緊貼 hero，Trust Bar，一屏內就要，唔可以放去 page 中間）：
一行徽章 + 一句數字，直接喺掃描框下面或緊隨其後：
- 權威徽章：Google Search Essentials · Core Web Vitals · Lighthouse（證明跟業界標準，唔係自家發明）
- 數字：平均每個網站揾到 47 個問題 · 平均修後 +18 分 · 3 分鐘出結果
- 付款/保障徽章：Stripe 安全付款 · 7 日退款保證
呢項第一屏就要，因為生意人掃一眼就要決定「呢個係咪吹水」——權威徽章 + 具體數字就係第一屏障。

第二層（中頁，唔係初屏）：
真實客戶 case snippet / 引用（初次 release 未有一律留 blueprint 位，填「要 Yan 提供」placeholder）＋「每條 finding 附實測證據，唔係模板」一句。

第三層（定價頁 + checkout）：
Stripe 安全付款徽章 +「交付前可退 / 交付後免費重審」徽章，緊貼付款實際動作位（呢個先係最需要降 risk 嘅時刻，唔係首屏）。

### 一個 hero 硬 rule

Hero 成屏只得一個 action（scan）。唔好同時放「睇 demo」＋「睇定價」＋「sign up」三個掣——一多路就散咗 conversion（landing-pages skill）。任何 secondary 連結放去 sticky nav 就得。
